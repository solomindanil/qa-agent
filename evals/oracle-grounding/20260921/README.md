# Source-grounded assertions and agent interpretation

Date: 21 September 2026. This is bounded offline skill evaluation, not product acceptance, a hosted benchmark or a new oracle runtime.

## Why this slice exists

The [preceding real controlled execution](../../public-input-agent-cycle/20260921/README.md) found useful search diagnosis but two assertions that rejected healthy summary wording. That immutable sample stays unchanged. Its fresh consumer had already corrected the assumption; the existing skill also already required grounded expectations. The follow-up therefore tests a small clarification rather than assuming that missing prose caused the failure.

The new appointment-preview task deliberately mixes semantic display requirements, exact legal copy, an API denial code, no-created-booking state and money/currency invariants. It asks for an offline authored oracle module plus its sources, limits and next actions. Generated modules are **experimental outputs, including known faulty ones; never import them into the QA runtime**.

## Method and first results

Five fresh-context agents per wording variant, configured Codex/gpt-5.6-sol/high, use the complete selected qa-product-v0 skill and the same raw task. The original first attempts are retained. Actors do not receive the controller probe, other answers or intended verdicts. They share a filesystem: this is not enforced answer-key isolation. Operational completion reminders are disclosed in the archived method record. No human supplied semantic answers.

The controller executes each module on 21 common captures, with four separately reported areas per capture. These are repeated observations, **not 420 distinct requirements or product checks**. An independent Lead AQA reviewed and strengthened the probe before skill edits. Two subsequent evaluator corrections are retained: structured explanations were initially overconstrained to strings, and honest abstention was initially conflated with wrong verdicts. The final soundness/coverage rubric is applied equally to every cohort without replacing original outputs.

## Completion rather than permanent abstention

A separate fresh actor receives five new supplied fixture captures, the original brief and one already-authored module. It must run that module unchanged, preserve its results, and complete the possible checks through a separately attributed agent assessment. The captures include valid alternate copy, contradictory meaning, wrong observable state, unknown-date inventory and prescribed exact copy. This remains offline fixture interpretation, not an attested browser campaign or a changed runner receipt.

This first separate continuation was completed against lane-1 without edits:14 fixture outcomes passed,5 failed,1 remained unresolved. Independent Lead AQA recomputed all five saved module returns and verified equality. It demonstrates useful bounded interpretation, not successful first-attempt boundary compliance for the entire candidate cohort.

## Review caught a missed case

Beyond the frozen21 set, Lead AQA changed the guest contradiction to `No sign-in is required`. Lane-2 and lane-4 wrongly passed it. Their positive regexes had merely missed this synonym in the earlier probe. This separate diagnostic is retained for every cohort in the archive; its two inputs are not added retroactively to the frozen denominator. A valid `You cannot book without signing in` is also checked and unresolved results remain coverage gaps, not PASS.

The final bounded wording iteration makes the existing two-artifact contract explicit: deterministic checks capture unrestricted prose without assigning its meaning; the agent assesses complete text separately. Exact source-prescribed copy, authoritative grammar and strict state/amount controls remain eligible for deterministic checks. The separate assessment cannot rewrite the original module return or runner receipt. No model-driven classifier or new runtime is added.

Manual review then challenged the summary, not just the guest message: `No appointments available. Booking 1 appointment is not possible.` with the known one-item fixture. Contract-3/4/5 falsely pass availability by extracting the numeric substring. Contract-1/2 leave meaning unresolved. Lead AQA independently reproduced this same-target error. The source wording is sound, but its intended behavior is not dependable in these samples.

## Decision and next step

**Do not select the candidate as a verified repair.** Console remains `c421160a71c0679a357f29828029ec3550791d16`; the manifest, runtime, installed skills and previous campaign receipts are unchanged. Stop this prose-only fix loop; no fourth variant, generated-parser engine or sampled-output repair is planned.

Reuse the existing independent test-design review before the next actual execution. The reviewer must check the complete source-backed claim against healthy alternate wording and contradictory complete text, not merely the authors' self-tests or a green fixed probe. Preserve original deterministic returns and separately attributed agent interpretation. Then qualify full-known-scope/ticket/help continuation through the real existing tools on a permitted unfamiliar product. This experiment does not replace that larger exit.

## Boundaries

The change is limited to the two identical existing product-analysis references. Entry metadata, runner, schemas, Kernel pin and permissions do not change. Codex/Claude source parity is not actual Claude execution or installed-host qualification. No live product, payment, tracker, installation, cloud or external publication is performed.

This small, non-randomized set establishes neither broad natural-language correctness nor a reliability percentage. Generated-module soundness, residual semantic coverage and subsequent agent interpretation must be reported separately. The offline coding task creates parser-writing pressure that ordinary agent-led QA need not have. Full P3/P5, real unfamiliar-product execution, crash continuation, broader graph benefit and cloud readiness remain open.
