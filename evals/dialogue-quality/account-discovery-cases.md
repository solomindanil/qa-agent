# Account-capability discovery comparison — cases draft

This is a two-case, source-only comparison of the existing root QA entry against a proposed root index/router revision. It does not replace the eight account-capability decision controls. Freeze these prompts, the separate rubric, both source revisions, and the actor setup before the first attempt. Do not execute a product, browser login, mail/provider operation, tracker write, or account change. The actor should answer what route is supported, what remains unverified, the next safe step, and a concise user-facing reply; proposed actions are not observations.

For each case, give baseline and treatment actors the **same** user request and synthetic owner context below, verbatim, with the same Freeland child source pin and the same host/model/tool availability. The arms differ only in the root skill index and root QA router bytes under test. Use fresh actors per case and arm; capture each first unaided answer and full tool transcript before any help or correction. The actor receives the selected root QA entry and ordinary repository access, but no expected command, target source filename, target effect list, reviewer rubric, or prior answer. Any broader files an actor finds must come from its own source inspection. If rubric/prior-answer access is not technically prevented, call the result open-context, not blind. Record elapsed time, model, tokens, tools and cost from evidence, using `unknown` rather than zero when unavailable.

The synthetic owner context is identical in both arms: this is an existing Freeland staging campaign whose product owner retains execution authority and frozen runtime. The source review may identify supported paths and gaps, but it authorizes no live product or provider action. No current account-readiness result or retained handoff artifact is supplied. Independently, the owner permits source-only/public-content analysis relevant to each request. No password, token, or session material is supplied or requested in chat. These facts say nothing about which source interface, side effects, or persistence mechanism an actor should find.
