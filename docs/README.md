The [source skills index](../skills/README.md) points to complete specialist instructions. A restored component has its own Git history, dependencies and commands. Read that specialist's current source and required references before product work; the root is not its working directory.

## Evidence and retained history

- [Qualification](qualification/) holds scoped source, runtime and product-lane reports, including the current checkpoint. Dated reports and their logs are evidence, not current instructions.
- [Evaluations](../evals/README.md) retain bounded agent and harness trials, including failures and inconclusive results.
- [Review reconciliation](reviews/2026-09-27-external-review-reconciliation.md) records the external-review disposition for this documentation pass; earlier reviews remain attributed to their dates.
- [Archive index](archive/README.md) identifies preserved former entries and plans. Their internal “next” wording and old absolute paths are historical.
- [References](../references/README.md) contains selectively retained inactive source snapshots, not another active runner or skill source.
- [Development source archives](../sources/candidates/README.md) retain bundle provenance. Only the manifest selects current source.

No file or bundle is classified as safely unnecessary merely because it is large or old. Cleanup should preserve exact bytes, hashes and relative links when evidence is archived; any future deletion requires separate provenance and dependency review.
