# QA-agent stable source release — 26 September 2026

Release preparation is in progress. This record will be finalized only after
local verification and published CI results are available.

## Frozen scope

The source base is `2f507fc`, before the unfinished W4 change-scope experiment.
Kernel `a0a20e6`, Console `f75d963`, Freeland `0ea2df1` and inactive reporting
reference `10d398d` retain their exact manifest-selected commits and bundles.
No component code, source pin, product campaign, installed host skill or account
state is changed by this release. Historical and candidate bundles are inactive.

Use [Getting started](../getting-started.md) and explicit source-skill routing.
The baseline supports the existing bounded local QA workflows; it does not
promise full product coverage, deterministic agent reasoning, Windows/cloud
execution, or automatic adoption of work still under development.

## Isolation

Release work runs in an independent Git clone with its own dependencies, build
outputs and temporary stores. The active QA FREELAND and MagicPay owners retain
the original source checkout, private registries, browser state and frozen
campaign runtimes. No shared working branch or installed skill is switched.
No product, payment, tracker or provider call is part of these release gates.

## Public delivery review

The owner explicitly requested public publication after the portability audit.
The release retains project-specific knowledge and historical qualification
records; old private-delivery approval is not re-described as public review.
Gitleaks 8.30.1 was checksum-verified and used locally on root history and on
all 57 reachable historical Git bundles materialized into an isolated object
store. The root scan inspected 197 commits and the bundle scan 441 commits
at the superset source snapshot. Its 33 + 49 findings were inspected: synthetic
negative-test tokens/keys, loopback test TLS material, idempotency strings,
integrity hashes and prose, with no confirmed operational credential found.
This is a heuristic credential scan, not a guarantee about every possible
encoding or a claim that all historical business context is generic.

Component/skill license files are preserved. No new umbrella license is applied
to material whose existing attribution differs.

## Verification

Candidate checks completed locally: root restore/verify and 61/61 packaging
checks; Kernel typecheck/build and 515/515 contract tests; Console typecheck and
production build. The first 163-test Console invocation had 161 pass, one path
assertion failure and one 180-second timeout. The path failure was reproduced
as macOS temporary-path aliasing; with a canonical isolated TMPDIR the unchanged
portability file passed 6/6. The separate paired-observation retest, wider Kernel
suite, Freeland offline suite and browser controls are still pending here.

The branch is a release candidate until the final verification record and hosted
CI are complete. The new runtime-smoke workflow uses canonical runner-private
state and only explicit pinned sources. It installs locked dependencies with
lifecycle scripts disabled, builds the pair, exercises contract/API/observation
controls and re-verifies source integrity. Existing source-safety CI stays
separate and unchanged. These gates do not attest live-product acceptance.
