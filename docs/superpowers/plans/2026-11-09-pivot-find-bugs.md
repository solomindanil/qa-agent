# Поворот 9 ноября 2026: искать баги, а не только доказывать покрытие

Основание: [адверсариальное ревью направления](../../reviews/2026-11-09-direction-review.md). Коротко: за 2026 год движок Console/Kernel не нашёл ни одного подтверждённого продуктового бага, около 150 найдены агентами и людьми мимо движка; на эталоне ToolShop (94 бага, цель ≥85) независимый оценщик насчитал 8/94, затем 3/94; в [глобальном плане](2026-10-05-universal-qa-product-plan.md) 4 закрытых пункта из 186. Владелец принял решения D1–D10 ниже со значениями по умолчанию 9 ноября 2026.

Этот документ — действующая очередь. Глобальный план остаётся инвентарём карточек; из него планируются только карточки, которые служат поиску багов на эталонных продуктах, в порядке этого документа.

## Что сохраняется

Оракульный реестр с утверждением человеком; честный знаменатель (verified / failed / blocked / unassessed, UNKNOWN не ноль); receipts, привязанные к SHA, и read-only mirror для денежных флоу и GO/NO-GO; методика (`METHODOLOGY`, `qa-product-v0` references, `qa-bugfix`); Freeland pack; Playwright-адаптер и грамматика проверок как ядро для расширения.

## Что заморожено (D3)

Console: `src/lib/agent-memory*`, `src/node/agent-memory*`, `src/lib/agent-request*`, `src/node/agent-request*`, continuation-пути, UI-монитор. Kernel: `src/kernel/agent-memory-*`. Новые `schemaVersion` и digest-поля без прямой пользы для поиска багов. Новые protocol/perf-тесты в обязательном CI. Расширение документации без удаления старой.

Исправления дефектов в замороженных областях допустимы, если они рвут путь пользователя (регистрация, видимые причины ошибок, чтение отчёта).

## Критерий приёмки среза (D2)

Каждый срез публикует одну таблицу в `current.md`:

| Поле | Содержание |
|---|---|
| Эталон | ToolShop (оценщик независимый, эталон закрыт от актора) и второй продукт |
| Найдено / пропущено | по эталону, до и после среза, тот же бюджет времени |
| Время до первой полезной проверки | от команды до первого PASS/FAIL с evidence |
| Доля времени | инструмент vs продукт |
| Ложные PASS | должно быть 0; одно ложное подтверждение = срез не принят |
| Ограничения | что не измерено |

Срез без прироста на эталоне не принимается, какой бы GO ни стоял. Критерий остановки поворота: если после двух срезов S1–S2 прирост на эталоне меньше 2× относительно 3/94, остановиться и перейти к варианту B ревью (развивать только методику и Freeland pack).

## Процесс (D6)

Дизайн-гейт остаётся: перед кодом среза — короткая записка (цель, файлы, контроли, измерение). Astra вызывается только для архитектурной развилки (новый контракт, схема, lifecycle); остальное решает автор с владельцем. Ревью — слепой ридер: diff, evidence, таблица измерения, без рассуждений автора. В `current.md` на срез — одна строка процесса и таблица измерения; журнал квалификации не расширяется.
