## What was cleaned, and what was not deleted

Active entry pages no longer duplicate dated queues or present old candidate labels as today's selection. The roadmap is a pointer; the architecture note explains product-owned engines and the supported common workflow. This is documentary unification, not a runtime migration.

No tracked evidence, bundles, failed attempts or product records were deleted or moved. Inspection did not establish a safely disposable tracked cohort. Old bundles can be required to reproduce attributed results; merely counting copies or their size does not establish redundancy. Any future pruning requires an explicit target list, dependency/reachability checks and a recoverable retained source.

Some historical links reference optional private records that are not delivered. Do not require those paths for first use, reconstruct missing evidence, or silently promote a result whose evidence is unavailable.

For routine source work search manifest-selected components and active root tools/tests/skills. Expand to history only for a stated question. Do not install archived skills or run legacy product suites because a historical document or current working directory mentions them.
