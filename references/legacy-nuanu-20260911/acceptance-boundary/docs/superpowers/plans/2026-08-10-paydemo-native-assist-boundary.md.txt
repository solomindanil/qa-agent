# PayDemo Native Assist Boundary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the proven `resolve_flow_item` Artifact MIME blocker and run one bounded native Assist canary that proves the repaired boundary, automatic column entry, and fail-closed status behavior.

**Architecture:** Reuse the active Nuanu Flow Column Process instead of creating another controller or Process. Pause the binding, make one minimal semantic patch that removes an unnecessary derived identity Artifact while preserving the immutable source `flow_item` reference and closed identity data, read the graph back, then open a short Assist-only canary window. The run yields either a completed pipeline or one exact next blocker; it never retriggers, purchases, or enables Auto.

**Tech Stack:** Nuanu Flow Process v1 through plugin 0.3.11, compact MCP catalog `sha256:ce6b998677428813fb780aebe0c47edb6fb80dfe4a726a7b5fdb0cbe1349fe5a`, Nuanu native remote worker plugin 0.3.14, Markdown verification evidence, Git.

- This is a platform canary in workspace `demo`, not a Freeland product verdict.
- Project is `PayDemo QA Harness` (`906cbb3d-32a1-4f44-b569-4e2b792ac3d3`).

- Source state is `Ready for QA` (`20b71a86-35b7-4ac0-a694-f2519f83d3cc`).
- Safe staging state is `In Progress` (`1eb21488-2e9c-4db4-8f66-7594d8566d93`).
- The canary Flow item uses `execution_mode:"assist"`; never set it to `auto` in this plan.
- The generated `project_start` and its immutable `flow_item` Artifact are never patched.
- The bound Agent remains `Universal QA Codex Runner` (`a07916ff-deab-4479-bf77-6f410c6f92c2`) at version `c70b2356-1fb2-47df-825a-7021d508a6e2`.
- Never upload or record tokens, credentials, cookies, PAN, CVV, signed URLs, or raw worker environment values.
- No payment, checkout, product mutation, Freeland browser action, stop, or takeover is authorized by this plan.
- Pause the binding before graph mutation; after the canary, pause it again and read back the paused state.
- Never retry or explicitly retrigger a failed canary. One Flow-item state entry produces at most one authoritative journey.
- A `409` or stale definition is not permission to merge or overwrite. Re-read once; otherwise stop with the exact blocker.
- Fix blocking validation errors only. Record advisory and `LAYOUT_EDGE_*` diagnostics without semantic rewrites.
- Every Nuanu mutation requires an immediate read-back before the next mutation.
- The seven older `2026-08-07-freeland-*` plan drafts remain untouched and unstaged.
