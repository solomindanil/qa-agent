# Nuanu Flow Deep E2E QA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Build and execute a guarded, layered E2E campaign that covers every visible Nuanu Flow module, performs owned CRUD only in NF QA Sandbox, and files independently confirmed defects only in Nuanu Flow project NUANU.

**Architecture:** Keep the anonymous Playwright baseline independent, add an opt-in authenticated project, and centralize sandbox identity, QA E2E naming, cleanup ownership, and route readiness in fixtures and page objects. Combine conditional Playwright automation with signed-in Chrome recon and Nuanu Flow MCP/API parity checks; mutable suites run serially and clean up only exact IDs created during the current run.

**Tech Stack:** TypeScript 6, Playwright 1.61, @axe-core/playwright, Nuanu Flow MCP, authenticated Chrome browser automation, Node.js.

## Global Constraints

- Target application: https://flow.nuanu.com.
- Mutable test workspace: NF QA Sandbox, exact slug nf-qa-sandbox.
- Stable host project: NF QA Sandbox, exact UUID 2c2298c0-7bdc-42a5-a5f5-54ad2cb5d3cf.
- Every created entity name begins with exact prefix QA E2E and includes a unique run ID.
- Never mutate pre-existing sandbox records; cleanup may delete only exact IDs registered by the current run.
- Confirmed bugs are filed only through Nuanu Flow MCP in workspace nuanu-flow-qa, project NUANU, never Linear.
- Do not connect personal third-party integrations or send real invitations, emails, messages, calendar events, payments, or notifications.
- Public tests must run without credentials or storage state.
- Authenticated Playwright tests activate only when NUANUFLOW_STORAGE_STATE names an approved gitignored file.
- Mutable authenticated specs run serially and restore or remove every reversible change in finally blocks or fixture teardown.
- Use semantic locators and observable UI/network states; do not add arbitrary sleeps or universal networkidle waits.
- Repeat suspicious flaky-looking cases ten times before product-bug classification.

- [ ] **Step 3: Implement immutable constants and cleanup ledger**

Create sandbox-data.ts:

~~~ts
import { randomBytes } from 'node:crypto';

export const QA_PREFIX = 'QA E2E';
export const SANDBOX = Object.freeze({
  workspaceName: 'NF QA Sandbox',
  workspaceSlug: 'nf-qa-sandbox',
  projectName: 'NF QA Sandbox',
  projectId: '2c2298c0-7bdc-42a5-a5f5-54ad2cb5d3cf',
});

export type OwnedEntity = {
  kind: string;
  id: string;
  name: string;
  workspaceSlug: string;
  cleanup: () => Promise<unknown>;
};

export type ResidualEntity = Pick<OwnedEntity, 'kind' | 'id' | 'name'>;

export const createRunId = (workerIndex: number, now = new Date()) => {
  const timestamp = now
    .toISOString()
    .replace(/[-:]/g, '')
    .replace('.000', '')
    .replace(/\.\d{3}/, '');
  return timestamp + '-w' + workerIndex + '-' + randomBytes(3).toString('hex');
};

export const qaName = (runId: string, suffix: string) =>
  QA_PREFIX + ' ' + runId + ' ' + suffix;

const assertOwned = (entry: OwnedEntity) => {
  if (!entry.name.startsWith(QA_PREFIX + ' ')) {
    throw new Error('Cleanup name must begin with ' + QA_PREFIX);
  }
  if (entry.workspaceSlug !== SANDBOX.workspaceSlug) {
    throw new Error('Cleanup workspace must be ' + SANDBOX.workspaceSlug);
  }
  if (!entry.id) throw new Error('Cleanup entity must have an exact ID');
};

export class CleanupLedger {
  readonly #entries: OwnedEntity[] = [];

  register(entry: OwnedEntity) {
    assertOwned(entry);
    this.#entries.push(entry);
  }

  async cleanupAll(): Promise<ResidualEntity[]> {
    const residuals: ResidualEntity[] = [];
    for (const entry of [...this.#entries].reverse()) {
      try {
        assertOwned(entry);
        await entry.cleanup();
      } catch {
        residuals.push({ kind: entry.kind, id: entry.id, name: entry.name });
      }
    }
    this.#entries.length = 0;
    return residuals;
  }
}
~~~
