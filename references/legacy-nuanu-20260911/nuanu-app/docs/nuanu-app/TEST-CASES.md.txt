# Nuanu App foundation test cases

This registry contains exactly the nine tests currently discoverable in the
foundation. Their graph disposition is `AUTOMATED`; a run result is assigned
only when a named campaign executes them. Nothing in this file is an evergreen
`PASS`.

## NAPP-CONTRACT-001

- Title: `NAPP-CONTRACT-001 synthetic runtime contract drives unique exact role-name discovery locators without network`
- File: `tests/nuanu-app/offline/runtime-contract.spec.ts`
- Full graph ID: `nuanu-app:auto:tests/nuanu-app/offline/runtime-contract.spec.ts#NAPP-CONTRACT-001 synthetic runtime contract drives unique exact role-name discovery locators without network`
- Graph disposition: `AUTOMATED`
- Oracle: an injected synthetic reviewed contract resolves exact accessible
  role/name locators with count one; duplicate and unavailable selectors stay
  `UNVERIFIED` instead of selecting an ordinal fallback.
- Safety: uses `page.setContent` plus a request canary and performs no product
  navigation.

## Discovery and execution

Discovery is the authority for whether these cases are currently automated:

```bash
NUANU_APP_BASE_URL=https://app.nuanu.com npx playwright test --list --project=nuanu-app
```

Execute the default project with:

```bash
NUANU_APP_BASE_URL=https://app.nuanu.com npm run test:nuanu-app
```

The optional `NUANU_APP_AUTH_STORAGE_STATE` is not consumed by these nine
cases. Physical iPhone and Android acceptance remains `MANUAL`; native
mobile applications remain `OUT_OF_SCOPE` for V1.
