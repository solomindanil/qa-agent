# Nuanu App foundation coverage map

This map describes registered coverage, not historical or current pass state.
Every `PASS`, `FAIL`, or other execution result belongs to a separate named
run.

The complete titles and graph IDs are in [TEST-CASES.md](TEST-CASES.md). The
starter mappings bind exactly these nine discovered cases. Fresh validation
fails when a mapped test disappears from discovery. A later plan rejects a
persisted graph when its discovery attestation changes. Fresh validation may
accept an additional unmapped discovered test; that test remains outside
mapped selection until its graph relationship is reviewed.

## Planner and result accounting

The graph dispositions are `AUTOMATED`, `MANUAL`, `BLOCKED`, `UNVERIFIED`,
and `NOT_DEPLOYED`. The planner produces disjoint `selectedAutomated`,
`manual`, `blocked`, `notDeployed`, and `unverified` buckets. Execution then
records exactly one per-run result from `PASS`, `FAIL`, `EXPECTED_FAIL`,
`FLAKY`, `MANUAL`, `BLOCKED`, `UNVERIFIED`, `NOT_DEPLOYED`, or
`INCONCLUSIVE`.

Optional aggregate telemetry retains its own `AVAILABLE`, `BLOCKED`,
`NOT_INSTRUMENTED`, `UNAVAILABLE`, or `SUPPRESSED` status. Those statuses do
not enter case-result or graph-disposition buckets.

## Identity and artifact chain

```text
reviewed mappings
  + runtime catalog
  + accepted runtime contract
  + selector observation/capture plan/bindings
  + optional clean source lock
  + discovered Playwright catalog
        -> validated graph
        -> impact
        -> dry-run test plan
        -> final plan-commit marker
```

`source-lock.json` attests inspected source only. `runtime-catalog.json`
attests observed public runtime only. Neither artifact alone proves that an
upstream commit is deployed. URL-only planning therefore keeps source impact
`UNVERIFIED`; source-only nodes cannot claim live coverage.

All graph artifacts live under the fixed gitignored
`docs/local/nuanu-app/product-graph/` tree. The final marker is the commit point
for a plan; partial impact or plan files without a matching marker are not
consumable evidence.
