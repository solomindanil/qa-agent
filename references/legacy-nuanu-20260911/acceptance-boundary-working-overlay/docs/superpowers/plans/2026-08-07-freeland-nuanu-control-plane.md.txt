# Freeland Nuanu Control Plane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove and implement the Nuanu-native path from an exact QA-column entry through a remote Codex agent and BPMN Decision to an auditable Manual/Assist outcome, without building a duplicate workflow engine.

**Architecture:** Product-neutral TypeScript contracts validate the deployed Nuanu build, exact state UUIDs, server-generated Column Start, worker envelope, proof ledger, and missed-entry audit. Nuanu remains authoritative for graph validation, activation, journeys, worker leases, human Decisions, Artifacts, and transition receipts. Live probes run first in an isolated sandbox and only then create the exact Freeland QA binding; the selected Flow item, not the binding, starts in Manual mode.

**Tech Stack:** TypeScript 6, Playwright test runner's `program` project, Nuanu Flow structured graph v3, official Nuanu MCP, Codex App Server remote worker, SHA-256 canonical JSON, versioned Nuanu Artifacts.

```ts
const SHA256 = /^[0-9a-f]{64}$/u;
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[1-5][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/u;

export function assertProjectStatePins(value: unknown): ProjectStatePins {
  if (value === null || typeof value !== 'object' || Array.isArray(value)) {
    throw new TypeError('project state pins must be an object');
  }
  const input = value as Record<string, unknown>;
  const ids = ['projectId', 'qaStateId', 'readyForProdStateId', 'inProgressStateId'] as const;
  for (const field of ids) {
    if (typeof input[field] !== 'string' || !UUID.test(input[field])) {
      throw new TypeError(`${field} must be a canonical UUID`);
    }
  }
  const states = [input.qaStateId, input.readyForProdStateId, input.inProgressStateId];
  if (new Set(states).size !== 3) throw new TypeError('production state IDs must be distinct');
  if (typeof input.workspaceSlug !== 'string' || typeof input.projectIdentifier !== 'string') {
    throw new TypeError('workspace and project identifier are required');
  }
  return Object.freeze({
    workspaceSlug: input.workspaceSlug,
    projectId: input.projectId,
    projectIdentifier: input.projectIdentifier,
    qaStateId: input.qaStateId,
    readyForProdStateId: input.readyForProdStateId,
    inProgressStateId: input.inProgressStateId,
  }) as ProjectStatePins;
}
```

- [ ] **Step 3: Implement the closed graph**

The graph builder produces this semantic spine:

```text
generated Start
  -> run_qa agent_task (closed runner command, structured output)
  -> verdict XOR (simple conditions only)
       PASS          -> pass_end
       PRODUCT_FAIL  -> product_fail_end
       otherwise     -> human_review Decision
                           approve -> qa_hold_end
                           deny    -> denied_hold_end
                           refine  -> run_qa
```

This intentionally compiles the design's logical freeze/plan/lane/join/
aggregate/freshness stages into the one closed worker task. It preserves the
same deterministic stages and evidence while preventing ticket data or BPMN
configuration from selecting a phase, executor, or retry independently.

Use these exact process-facing output fields:

This product-neutral repository validates `qaRunKey` as the exact lowercase
64-hex wire string. The FreelandQA boundary then converts it through its sole
`asQaRunKey` validator into the branded `QaRunKey`; no unchecked cross-repo
TypeScript cast is shared.

The Nuanu process supplies only `QaWorkerSeedV1`. Before the closed command is
dispatched, the adapter canonicalizes the validated seed, derives its SHA-256,
and calls `PreparedQaInvocationPort.materializeOnce`. Only that atomic port may
invoke the supplied preparation callback. On the first delivery the callback
uses the trusted FreelandQA runner port to load its reviewed registry, plan the
exact requirement closure, derive the complete identity and `qaRunKey`, and
return one frozen `QaWorkerInputV1`; the invocation port durably commits its
canonical JSON before returning a receipt. Concurrent/reclaimed deliveries for
the same seed digest return the exact committed bytes and never call `prepare`
again. The adapter validates the receipt/digest, reparses the committed bytes,
and requires the prepared value to differ from the seed only by the key with
every seed field byte-identical. The N0 server capability probe and Manual
acceptance must prove a production implementation of this port; if the deployed
protocol cannot provide it, the graph stays inactive.

`createDurablePreparedQaInvocationPort` is the production single-host worker
implementation. It accepts only the statically composed absolute runtime root,
creates owned `0700` directories and immutable `0600` content-addressed files,
uses atomic create/fsync/link semantics, validates owner/mode/realpath/link
count and canonical bytes on every read, and never overwrites a committed
seed. A crash before publication may prepare again because no dispatch was
possible; a crash after publication always replays the committed receipt.

Task 3 also builds these adapter sources and the two exact schemas into
`@nuanu/freeland-worker-adapter@1.0.0`. The package contains compiled JavaScript,
declarations, and schemas only; it has no install script, Nuanu credential,
runner implementation, dynamic loader, caller-selected network endpoint, or
general network client. Package-archive output is not imported from a sibling
checkout. N1 vendors the reviewed
tarball and pins both its SHA-256 and this repository's exact source commit
before a live worker may load it. The package also exposes the closed inherited
worker-control client: the official Nuanu transport passes an authenticated
socket as file descriptor `3`, outside task JSON. The client verifies the
signed deployment/session pin, mode-specific handler-spec digest, closed
`manual | assist | auto` execution mode, and peer, then permits only frozen
Flow-item freshness reads and one content-addressed sanitized Artifact-version
publication. The server atomically claims `(task, qaRunKey, name)` before
creation: an exact digest replay returns the original three-field reference,
while a changed digest/name or second distinct publication fails closed. It exposes no
general MCP call, item mutation, Decision, route, URL, token, or arbitrary
request method. A missing/unauthenticated inherited control channel keeps the
task uncompleted and the binding inactive.

For each claimed task the transport resolves the selected Flow item's binding
and authoritative process-control record, reads its closed execution mode, and
selects the separately immutable handler-spec/deployment-pin pair for that
mode. Neither the seed, task JSON, ticket text, graph, parent environment, nor
worker CLI may propose or override the mode or either digest. The mode is part
of the authenticated session transcript and every signed freshness response.
The worker's pinned environment, handler manifest, deployment pin, and session
must agree before preparation or `qaRunKey` derivation. Because
`captureFreshness` requires the prepared `QaWorkerInputV1`, its first response
then cross-checks that same mode immediately after envelope validation and
before execution authority, any lane, or publication.

`createInheritedNuanuWorkerControlPort` takes exclusive ownership of FD `3`
immediately, wraps it in one private auto-closing socket, and exposes neither
the number nor the socket. The caller cannot duplicate, detach, transfer, or
retrieve it. Every ordinary process spawn in the worker program declares an
exact `stdio` array containing only reviewed descriptors `0`–`2`; no child ever
inherits or aliases the Nuanu worker-control endpoint. The sole exception is
the statically selected CDP/payment host daemon: its spawn may map a newly
created one-shot 32-byte host-key pipe to one reviewed child-local descriptor.
That pipe is cryptographically and descriptor-identifiably distinct from the
Nuanu socket, cannot carry worker-control frames, and is read and closed before
the host binds. All of that daemon's descendants then observe the descriptor as
`EBADF`. Closing the control port makes the original worker descriptor
observably `EBADF`. Package tests keep the control channel open, start fixed
ordinary and host-daemon descendant probes, and prove the Nuanu endpoint is
never inherited, the one-shot pipe cannot alias it, and every unreviewed
descriptor returns `EBADF` before live activation.

The seed and result schemas under `src/nuanu/schemas/` are exact independently
validated wire copies of the corresponding FreelandQA v1 schemas and are pinned
by SHA-256 in the adapter test. `executeFreelandQaTask` validates the complete camel-case result,
requires its `qaRunKey`, issue revision/content digest, candidate identity, and
sole artifact to match the prepared input, and requires
`result.artifacts.length === 1`. It then maps only the nine exact fields of
`QaWorkerOutputV1`; no generic `TResult`, agent prose, or extra artifact can
reach the process outputs.
