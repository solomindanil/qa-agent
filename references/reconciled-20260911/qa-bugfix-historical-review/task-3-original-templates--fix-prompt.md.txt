# Fix prompt template

Generated by `qa-bugfix` — one prompt per bug cluster. The prompt must be fully
self-contained: the executing agent knows nothing about the QA session.

```markdown
You are fixing <N> confirmed, QA-verified bug(s) in <product> (<stack, if known>).
Tickets: <TICKET-ID(s) with Linear URLs>. Scope: exactly these bugs — no unrelated
refactoring, minimal diff.

## Bug 1: <symptom> (<TICKET-ID>, severity: <level>)

**Reproduce:**
1. <exact steps, URLs, inputs>

**Expected:** <correct behavior>
**Actual:** <wrong behavior — exact UI strings in quotes, status codes, endpoints>
**Evidence:** <screenshot URLs from the ticket, curl output, console text>
**Likely area:** <grep hints: exact literals, endpoint paths, component names — NOT prescriptive>

<!-- Repeat per bug in the cluster. Explain why they are one cluster (shared root cause). -->

## Acceptance criteria

- [ ] <observable behavior 1 — phrased as verifiable outcome>
- [ ] <observable behavior 2>
- [ ] No regressions in <adjacent behavior that must keep working>
- [ ] Project's typecheck / lint / tests pass
<!-- If the QA repo has a regression test: -->
- [ ] The QA suite's `test.fail()` regression for <TICKET-ID> now reports
      "expected to fail, but passed" — i.e. the bug is gone

## Recommended workflow (adapt to your capabilities)

- **If you have subagents:** first use a search/explore agent to locate the code
  from the literals above; after implementing, run an independent code-review
  subagent on the diff before finishing.
- **If you have browser tools:** reproduce the bug before changing code; re-verify
  visually after the fix.
- **If you have a Linear MCP connection:** move <TICKET-ID(s)> to "In Progress" when
  you start; when finished, add a comment summarizing the change. Do NOT mark the
  ticket Done — QA re-tests the live product and closes it after verification.
- **Always:** plan before editing; keep the diff minimal; run typecheck/lint/tests;
  if a fix requires a product decision (copy, pricing, design), stop and ask instead
  of guessing.

Commit as: `fix: <symptom> (<TICKET-IDs>)`
```
